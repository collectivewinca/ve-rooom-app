# Changelog

All notable changes to this project are documented here. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Formal VE Lab open-source governance and community health files.
- Deploy to Cloudflare configuration and binding descriptions.
- GitHub Actions for CI and CodeQL, plus Dependabot configuration.
- Persistent local pseudonymous identity for self-contained deployments.

### Changed

- Migrated hosting from Cloudflare Pages to one Cloudflare Worker with Static Assets.
- Updated development and deployment commands for Wrangler 4.
- Removed account-specific defaults and private operational details from public documentation.

## [0.1.0] - 2026-10-28

### Added

- React meeting application using Cloudflare RealtimeKit.
- Composite recording lifecycle and R2 durable-copy path.
- Transcript and multi-provider summary pipeline.
- Meeting dashboard, summary history, downloads, prompts, and email delivery hooks.
