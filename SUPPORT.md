# Support

## Questions and ideas

Use GitHub Discussions for setup questions, architecture discussions, and feature ideas. Include your Wrangler version, browser, and relevant non-secret configuration.

## Bugs

Use the bug-report issue form after searching existing issues. Provide minimal reproduction steps and sanitized logs.

## Security

Do not report vulnerabilities publicly. Follow [`SECURITY.md`](SECURITY.md).

## Scope

Community support is best-effort. Maintainers cannot provide support for Cloudflare account billing, RealtimeKit enablement, third-party LLM accounts, or modified private deployments. Use the relevant provider's official support channels for platform-specific account problems.
